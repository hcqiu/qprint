## 哪些用途免费

| 场景 | 是否需要商业授权 |
| --- | --- |
| 个人学习、整理笔记、无商业目的的个人项目 | 不需要 |
| 非营利学校的常规教学、学生课程作业 | 不需要；常规学费和教师薪酬本身不改变性质 |
| 非营利高校、研究机构的独立非商业学术研究 | 不需要；公共科研经费、奖学金本身不改变性质 |
| 学校或课题组为符合条件的师生研究成员部署内部服务 | 不需要 |
| 公司内部使用、研发、评估，或员工代表公司使用 | 需要，即使不对外发布或不直接收费 |
| 企业委托研究、为企业进行的研究、面向商业产品的研究 | 需要；无商业交付或优先商业化权利的无条件捐赠本身不算 |
| 收费咨询、商业培训、商业 SaaS、广告支持或业务推广服务 | 需要 |
| 向公众提供托管 Qprint 服务或 API | 需要，即使免费；学校内部教学科研服务按上面的例外处理 |
| 集成进商业产品、打包销售、转售或收费再授权 | 需要 |
| 免费分享原版或修改版，用于符合条件的非商业用途 | 不需要，但须保留许可证和版权声明、标注修改，不得额外授予商业权利 |

个人身份、学术标签或免费提供服务都不自动豁免商业授权要求。授权取决于实际用途及 LICENSE 中的边界。
